Luna Tartas

A website for Luna’s handmade gifts: diaper cakes, stationery and personalized details. The catalogue organizes products by type, occasion and recipient.

The decision

Publish a useful catalogue with little maintenance. Static generation fits that rhythm: validate content, build the website and publish.

Decisions

Proportional architecture avoids adding a backend, CMS, database or accounts where the current domain does not require them.

Static-first reduces runtime infrastructure; catalogue changes require validation and a new build.

What I built

  • Structured catalogue, content validation, SEO and static generation.
  • CI, consent-aware analytics and build-time deployment.

Current scope

  • The implementation uses static generation, not SSR.
